# 首页统计设计

在现有橙色页头与四块功能卡片之间新增「生活累计」，保持米白底色、衬线标题、黑色描边和硬阴影。

| 指标 | 统计口径 | 示例 |
| --- | --- | --- |
| 已记录 | 有记录的自然日去重；日记及记账采用记录日期，其他笔记采用创建日期；使用配置时区 | 128 天 |
| 创建笔记 | 当前有效的 LifeOS 笔记总量，包含归档笔记；不计账目、模板、附件及无法解析的文件 | 356 篇 |
| 完成项目 | 完成状态的项目；包含已归档完成项目，排除取消项目 | 12 个 |
| 完成待办 | 完成状态的待办笔记；包含已归档完成待办，排除取消项；正文勾选项不混入 | 86 项 |
| 读完书籍 | 阅读状态为已完成的书籍笔记；包含归档记录 | 18 本 |
| 知识积累 | 有效知识笔记，包含归档记录 | 64 篇 |

补充一行轻量提示：连续记录天数、本周新增笔记、最早记录日期。连续记录允许今天尚未记录时以昨天为末日计算；本周从周一开始。更新旧笔记不算新增。

效果图只使用示例数据。实际实现应读取完整索引，不能使用最近 20 条记录计算累计值。未启用模块显示「未启用」或隐藏；尚未读取完成显示占位，读取异常提示统计范围。零值显示为 0。

今天、快速记录、进行中事项、最近记录维持现有两列四卡布局。窄屏下统计指标排列为两列，四张功能卡依次纵向排列。

本次输出为设计方案及效果图，未修改业务界面代码。
