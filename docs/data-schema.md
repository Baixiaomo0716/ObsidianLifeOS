# LifeOS 数据契约

契约1.5；2026-10-10；PRD1.8；业务文件格式版本3。实际中文字段、原生tags和统一进度列表为当前规则。旧规则见[历史1.3](history/contract-1.3/data-schema.md)。

## 存储与兼容

九类记录每条一个Markdown文件，记账每行一个独立UUID.json文件。业务属性名和规定枚举值均为中文，界面和实际磁盘字段一致。技术配置、源码变量及恢复日志保留自身协议。

中文文件格式为3，旧拼音格式2仍可读取，编辑或明确迁移后写为中文格式3；未知版本只读。存储边界将两种已知格式转换为既有内部领域模型，不重写用户自定义嵌套内容。中文与拼音同名字段并存时停止，不静默覆盖。旧插件不保证识别格式3。

## 通用属性

| 字段 | 规则 |
|---|---|
| 标识 | 全库唯一UUID v4，不因改名或迁移重新生成 |
| 实体 | 日记、记账、阅读、影视、游戏、演出、旅行、知识、待办、项目 |
| 结构版本 | 新业务文件为3，不是编辑次数或插件版本 |
| 创建时间 | 原生日期时间，插件创建后不自动更改 |
| 更新时间 | 原生日期时间，插件实际更新时写入 |
| 已回收、回收时间 | 逻辑回收信息，路径与引用保留 |

九类笔记的标识、名称、已归档、已取消与其他指定移出属性栏的历史字段保存在隐藏系统注释。注释还保存属性模式与笔记时区，源模式可见，请保留；插件返回的自由正文不包括注释。当前属性模式为统一，旧简洁模式仍可读取。损坏的注释拒绝写入。

## 十类业务属性

| 类型 | 原生属性展示 |
|---|---|
| 日记 | 日期、天气、星期、农历、tags；日记写正文，不显示旧内容、关联属性 |
| 记账 | 日期、星期、收支、分类、标签、金额；无MD模板 |
| 阅读 | 作者、来源、类型、tags、字数、进度、简介、评价、评分、开始时间、读完时间 |
| 影视 | 类型、导演、主演、上映时间、观看时间、简介、评价、豆瓣评分、进度、tags |
| 游戏 | 类型、简介、发行时间、评价、进度、tags |
| 演出 | 类型、乐队名称、时间、地点、简介、评价、评分、进度、tags |
| 旅行 | 开始日期、结束日期、地点、交通工具、住宿、评价、进度、tags |
| 知识 | tags、内容、进度 |
| 待办 | 开始日期、截止日期、进度、tags；名称为文件标题，旧名称隐藏保留；不显示内容、关联、已归档、已取消 |
| 项目 | 开始日期、截止日期、进度、tags；不显示待办、上传文件、内容、已归档、已取消 |

九类笔记用原生tags，旧标签值迁移并与已有tags去重合并；独立JSON记账行仍用标签。导演、主演、乐队名称、地点、交通工具、住宿为列表；简介、评价、内容等长文本保持文本属性，源模式可写多行。分值0–10，字数非负整数。可选标量null为空占位，不以0冒充未知；非法非空值仍报错。

除日记外八类笔记统一使用进度列表，默认[未开始]，只保存三状态之一；多状态或未知值为无效初稿。阅读原状态字段兼容转换，知识新增进度。影视类型为电影、电视剧、纪录片、动画、综艺、其他，其他类型仍为自由文本。

日期为YYYY-MM-DD，开始日期不晚于截止/结束日期；上映时间、发行时间为日期。创建/更新时间、阅读开始/读完时间、观看时间、演出时间及完成/取消/回收时间为日期时间。初始时间含偏移；原生控件保存无偏移值时按隐藏的笔记时区解析，夏令时不存在或重复的时间需在源模式明确偏移。

无效初稿保留，完善后进入有效索引；校验不阻止原生自动保存。日记正文不受旧内容属性500码点限制，历史内容属性仍保留兼容校验。日记/待办新增标签为可选列表，新输入默认空列表。

## 文件名、进度、关联

日记保存为10_日记/YYYY-MM/YYYY-MM-DD.md；同日唯一有效记录复用，日期争议先处理。其他八类新建均为纯名称.md，同名不覆盖。现有UUID后缀通过单独备份改名移除，冲突保留可读编号。

八类进度在LifeOS校验侧栏提供安全三项选择，原生属性为列表。首次完成生成完成时间，重复完成保留，离开完成清除。阅读完成时间与读完时间同步。取消/归档不是第四种进度，历史标记隐藏保留。

关联用稳定标识，禁止自关联并按标识去重，缺失目标只报告；待办最多归属一个项目，项目待办列表反查归属。隐藏的历史关系和上传文件仍保留；附件路径必须相对Vault且真实存在。对应选择器/上传界面仍按后续任务实现。

更新比较完整原文，不用更新时间替代版本。未知属性和未编辑正文保留；非法YAML/JSON、别名冲突、未知版本或重复标识停止写入。

## 记账

收支为收入/支出，仅人民币，无账户、转账、退款。金额在JSON中保存为正安全整数分：12.50元对应1250，改名不改单位。有效且未回收行参与统计，草稿和冲突行排除。

```json
{"标识":"7184687e-9017-4db3-bc55-a0749d441ef2","实体":"记账","结构版本":3,"创建时间":"2026-10-09T12:30:00+08:00","更新时间":"2026-10-09T12:30:00+08:00","日期":"2026-10-09","星期":"星期五","收支":"支出","分类":"餐饮","标签":["午餐"],"金额":1250,"已回收":false}
```

## 附件导入元信息（DEV-017）

00_系统/附件/<标识>.json使用独立结构版本1，字段为标识、项目标识、名称（原名）、字节数、类型（来源MIME）、导入时间（带偏移ISO时间）、路径（Vault相对路径）、摘要（SHA-256）、结构版本。元信息是导入意图，实际文件缺失或摘要不符时不能视为可用附件。九类笔记/记账业务格式与契约1.5不变；项目引用继续保存在隐藏系统区。
