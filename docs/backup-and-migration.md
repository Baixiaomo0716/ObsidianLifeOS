# 备份与迁移执行约束

2026-10-09：当前按用户要求优先桌面，手机验收暂缓。备份包含权威Markdown、记账JSON、系统日志、冲突材料与附件；缓存不作为恢复权威。个人Vault未在本次操作范围内。

备份前停止编辑和同步，把指定数据复制或压缩到Vault之外，保留原文件；记录相对路径、字节数和SHA-256。恢复到新空目录，逐文件校验数量、路径和摘要，再用宿主重读和后续索引校验。不得覆盖当前Vault来试验恢复。

本地Vault外备份只能防范源目录误改，仍在同一磁盘时不能防范磁盘故障；长期备份需要另一个物理存储目标。目前未配置该目标。Git历史和同仓库副本不能替代独立备份。

当前结构版本2；旧版本保留只读。迁移必须先备份，再预览映射和无法映射项，用户明确执行后才修改；未知属性、正文和附件保留。转账退款不伪装为收支，多次经历不静默合并。当前没有迁移执行器。

本轮合成文件恢复证据见[同步与恢复](qa/sync-and-restore.md)。
