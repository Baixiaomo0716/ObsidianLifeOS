# 笔记模板正文格式

此文件集中保存各类笔记的正文格式，方便单独查看、复制与后续调整。正文不包含 YAML 属性和隐藏系统注释；实际新建笔记使用 templates/ 下对应的模板文件。开发时修改此汇总后，需要同步修改仓库中的对应模板。插件更新后，新建笔记会自动带入最新默认正文，无需用户手动同步已安装模板；用户自定义模板与已有笔记保持原文。

## 日记

日记以「记录当天状态 → 保存具体片段 → 简短回顾」为主，各项均可选填，片段数量可自由增减。天气属性用于日历展示与查询，正文天气用于写具体感受；如需两处都展示，请手动保持一致。心情和精力是自由记录，不参与属性校验或统计。

关联笔记可填写 Obsidian 双链并说明关联原因；正文双链不会自动转为 LifeOS 的稳定标识关联，请通过 LifeOS 关联功能管理正式关联。正文中的明日计划勾选项仅作写作清单；需要独立待办时，请新建待办笔记。

实际模板：[日记.md](../templates/日记.md)。以下内容可直接复制到笔记正文：

## 关联笔记

## 待办

实际模板：[待办.md](../templates/待办.md)。正文使用 Markdown 勾选清单；所有有效、未完成、未取消、未归档的待办笔记中的未勾选条目都会显示在首页「待办清单」，不受笔记日期限制。点击条目打开原笔记，在原笔记勾选后首页自动刷新。代码块和 HTML 注释中的范例不会被读取。

每条 TODO 使用「（截止：YYYY-MM-DD HH:mm）」填写独立截止时间，新建时默认当天 23:59，按笔记时区理解，可逐条修改。首页会随条目文字显示截止时间。首页「今日待办」仍按笔记开始或截止日期筛选；「待办清单」按正文条目展示。勾选正文条目不会自动更改整篇待办的进度或完成统计。模板中的示例会作为实际条目显示，请按需修改或删除。

```markdown
## 待办目标

这件事要达成什么结果：

## TODO 清单

<!-- 每条待办都填写截止时间，格式为 YYYY-MM-DD HH:mm；范例默认新建当天 23:59，可逐条修改。未勾选条目会显示在首页「待办清单」，勾选后移除；点击首页条目可打开本笔记。 -->
- [ ] 明确任务目标和完成标准（截止：{{date:YYYY-MM-DD}} 23:59）
- [ ] 整理所需资料与相关笔记（截止：{{date:YYYY-MM-DD}} 23:59）
- [ ] 完成第一版并检查结果（截止：{{date:YYYY-MM-DD}} 23:59）
- [ ] 确认交付并记录反馈（截止：{{date:YYYY-MM-DD}} 23:59）
- [x] 已完成步骤的范例（可删除）（截止：{{date:YYYY-MM-DD}} 23:59）

## 关联资料

- 

## 执行记录

- 遇到的问题：
- 下一步行动：

## 完成小结

- 最终结果：
- 经验与改进：
```

## 使用说明

九类笔记正文格式均已补齐。正文中的链接和记录是自由写作内容；需要在 LifeOS 中统计的进度、评分、日期等请填写对应属性，正式关联通过关联功能选择。项目中的具体行动请新建待办笔记并填写每条 TODO 的截止时间，以便首页展示。
