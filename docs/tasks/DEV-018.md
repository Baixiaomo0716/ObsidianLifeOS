# DEV-018：日记创建、编辑与日期浏览

2026-10-10；契约1.5，业务格式不变。工程已完成，桌面日期操作待体验。

LifeOS→回看→记录类型“日记”接入月份日历、日期选择、今天跳转、上一月/下一月、当天正文预览及原生编辑入口。日历从周一开始，只生成真实日期，显示已记录/需核对；按配置时区确定今天。日记搜索、标签筛选和关联入口仍保留在日历下方，复用DEV-015/016。

读取按笔记实际日期属性归组，手工改名、移动目录后仍可找到，不强制整理旧笔记。当天详情展示星期、农历、天气、tags和纯文本Markdown正文。正文预览有高度限制和滚动，不解析用户HTML，也不显示隐藏系统注释。点击“查看/编辑日记”在原生编辑器填写；本项不新增独立正文表单、自动改写天气或迁移属性。

新建复用DEV-014模板、UUID身份、日期派生与操作日志，默认路径年-月/年-月-日.md。一日已有一篇有效日记直接打开已有文件，不创建新日志、不改正文。快速重复点击用同步锁；未确认创建响应沿用原请求；打开编辑器失败只重试打开已保存路径，不再创建。

重复日期、重复身份、字段错误或不可读的日期文件显示需核对并暂停新建，提供打开原文件检查入口；不会删除、合并或自动选择其中一篇。标准位置有回收日记时提示恢复/核对，禁止覆盖原件。无法映射到具体日期的日记问题通过日记异常数量提示，完整性检查仍提供所有问题路径。其他类型同名错误文件不会误阻塞日记日期。

日期浏览只读，手工正文、未知属性、隐藏历史字段与tags保持。准备打开时重建索引；已有日记在执行前再次检查，若变为冲突或回收则停止。尚未初始化时显示读取状态并禁用创建；离开页面释放索引订阅，不在迟到回调中打开编辑器。

验证：228项自动化检查、类型检查、生产构建与产物检查通过。新增11项日记检查，覆盖时区今天、闰月真实天数、月份目录、同日重开不写、手工正文与未知属性/改名保留、同日重复报告、坏文件与类型隔离、回收保护、未确认创建与并发同日、卸载/伪造请求、日历切换、打开失败复用路径和争议日期原件检查。测试使用合成数据，未自动改写实际日记。

体验：Ctrl+R重新加载Obsidian，进入LifeOS→回看→日记，点击日期或选择月份，再点击创建并打开/查看编辑。直接在Obsidian编辑正文，返回LifeOS后会随索引更新刷新预览。真实桌面滚动、日期控件和编辑切换待宿主确认；手机暂缓。
