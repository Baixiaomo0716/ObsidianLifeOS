# DEV-023：收支规则与边界

2026-10-12；契约1.5，JSON结构不变。工程完成，手机暂缓。

统一分类规则assertLedgerCategory已接入记账新建服务。新建或重新分配分类必须使用对应收支类型的启用分类；编辑已有记录时可以保留原收支/分类组合，即使该分类被停用或移除。改变收支类型不能借历史分类绕过检查，也不能重新分配到停用分类。历史许可仅用于受信任原记录，不用于新建表单；DEV-024编辑服务接入时需读取并核对原版本后传入。停用分类不改写、隐藏或删除已有记账行。

金额只能使用元的十进制文本，允许首尾空格和前导零，最多两位小数；不接受数值对象、科学计数、千分位、货币符号、正负号、非ASCII数字或零值。最小0.01元，最大90071992547409.91元，对应最大安全整数分；超出一分即拒绝。BigInt转换与汇总避免浮点误差。累计收入或支出超出安全范围即报错，不返回部分统计；结余允许负数，回收行不计入。

中文旧转账、退款等非首期收支行保留原JSON，不进行猜测转换。重建索引报告字段问题，不进入正常搜索或统计。原文件及未知属性保持，完整性检查可定位；格式未知或损坏仍沿用只读保护规则。系统不自动新增账户、退款或转账功能。

保存前分类停用会阻止新建；已经尝试保存而回执未确认时，重试核对原请求，不因分类后来停用而重复创建或掩盖已有成功结果。此行为与历史保留规则一致。
