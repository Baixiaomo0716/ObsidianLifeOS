# DEV-015：搜索、筛选与反向关系

2026-10-10；基于契约1.5。工程已完成，桌面交互待体验。

回看页面查询真实索引中的九类Markdown笔记和独立JSON记账行。支持当前文件标题、正文、tags/账本标签及内容、简介、评价搜索；多个搜索词同时匹配，不搜索隐藏历史名称或标识。标签独立筛选精确匹配，支持输入前导#。

支持启用类型、进度和业务日期筛选。阅读兼容内部状态字段，其余八类笔记按统一进度读取；日记和记账不显示进度条件。类型切换重新创建筛选面板，清除不适用条件。每页50条，日期降序、路径稳定排序，结果变少自动收缩页码。查询只读，不修改业务文件。

日期按设置时区转换时间戳；纯日期不偏移。各类型可选择自己的业务日期字段；全部类型默认使用各类型首个业务日期：日记/记账日期、阅读开始时间、影视观看时间、游戏发行时间、演出时间、旅行/待办/项目开始日期。知识没有业务日期，限定日期范围时排除。日期范围包含首尾，缺日期排除，非法范围提示。

查看关联按内部ID解析，支持跨Markdown和JSON的正向及反向查询，忽略ID大小写并去重。目标不存在、回收或争议时保留缺失提示，不删关系。项目的被关联列表可以找到通过关联指向该项目的待办；不以历史项目待办属性双写关系。关联查询保留停用类型的历史引用，主列表按当前启用类型显示。

点击记录在原生编辑器打开当前笔记路径；记账暂以只读弹窗显示中文字段及元金额，专用编辑表单仍属DEV-022。查看关联不是关联编辑，新增/解除关联留待DEV-016。

索引在成功发布完整快照后通知界面。订阅取消、插件卸载、订阅抛错均处理；初始化完成前显示读取提示，读取/校验/重复ID等问题排除相应记录并显示问题数量。原有完整性检查命令提供进一步核对。

验证：183项自动化检查、类型检查、生产构建和产物检查通过。新增5项搜索服务测试、1项索引订阅测试和1项回看结果渲染测试，覆盖标题重命名语义、正文和标签、时间区间/类型字段隔离、反向关系/缺失目标、记账金额、分页收缩、订阅生命周期和实际结果展示。真实桌面筛选操作、滚动和打开记录仍需宿主体验；手机暂缓。

体验：重新加载Obsidian（Ctrl+R），打开LifeOS→回看，输入正文片段或标签，切换类型与日期，点击标题打开笔记，再查看关联。无有效记录时显示空状态，不添加示例数据。
