# DEV-020：待办存储与进度

2026-10-12；契约1.5，业务格式不变。工程完成，桌面操作待体验，手机暂缓。

TaskService复用九模板创建、统一索引和操作日志。标题即可创建待办，默认“未开始”，文件名为标题，重名沿用人类可读编号；业务属性采用中文、tags和进度列表，正文在原生编辑器填写。准备创建不写入，实际保存后创建；沿用同一创建请求重试不会重复生成笔记。不新增优先级。

支持未开始、进行中、已完成，以及撤销完成、取消待办、恢复取消。首次完成记录完成时间，重复完成保持原时间且不生成额外写入；离开已完成清除完成时间，撤销完成仅用于已完成待办并回到未开始。取消不是第四种进度，只更新隐藏取消标记和取消时间；重复取消保留首次时间。恢复取消清除取消信息，保留原进度和归档标记。普通进度切换也不清除取消标记。正文中的checkbox只属于正文，不自动控制进度。

保存前捕获原文件版本并重建索引，执行首次写入前再次核对；坏字段、开始晚于截止、回收、重复身份和原文件变化均暂停操作。更新只涉及进度/完成/取消信息，保留正文、日期、tags、关联、身份及未知属性。真实写入的更新时间由存储层维护。未确认响应沿用原操作日志请求重试，不重新生成完成时间；并发重复提交共用一次执行。已停止服务和外来请求不能写入。

打开有效待办后，通过命令面板执行“LifeOS：修改当前待办进度或取消状态”，选择操作并保存。失败时可重试同一操作；原文件冲突需关闭后重新打开核对。关闭尚未提交窗口不写入，已开始的保存可能继续完成并通知；窗口清理由插件管理，卸载后不弹出迟到通知。原生属性与校验侧栏的既有三态编辑保留。
