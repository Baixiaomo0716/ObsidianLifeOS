# DEV-014：九类模板新建与辅助编辑

2026-10-09；状态：工程完成，真实宿主新建、原生属性编辑及校验侧栏待验收。手机继续暂缓。

## 交付

首页日记/待办快捷按钮、记录页九类笔记按钮及九个新建命令接入真实创建服务。输入名称或日记日期后创建Markdown笔记，并在Obsidian原生编辑器打开。记账继续使用独立JSON，专用表单留DEV-022/023。

九份公开模板随插件打包；优先读取管理根的00_系统/模板/<中文类型>.md。不存在时使用内置模板，已有模板格式错误时停止创建。命令“安装九类笔记模板”仅安装缺失文件，不覆盖用户模板；逐项报告部分失败。支持{{title}}、{{date}}、{{date:YYYY-MM-DD}}、{{time}}；不支持的变量报错。新建时生成独立标识与创建/更新时间，日记按配置时区计算日期、星期、农历。

可选标量空属性在有效模型中视为未填写，原始属性和自由正文保留；必填属性、列表及非空无效日期仍校验。初稿可能缺必填业务字段，原生编辑器可以继续保存；校验侧栏只报告问题，不拦截自动保存，也不将无效初稿计入有效记录。日期时间须含Z或时区偏移，必要时使用源模式编辑。

新建请求固定操作标识，未确认写入后的重试沿用原请求；同日日记已有唯一有效记录则打开它，重复日期或异常索引阻止创建。本机并发新建按顺序处理，跨设备同时创建仍需同步冲突处理。

手动调用Obsidian核心模板生成的笔记，可以执行“初始化当前模板笔记的标识和时间”。仅支持管理目录、结构版本2且三个系统属性均空的笔记，仅补系统标识和时间，不改正文、业务属性或未知属性。请求写入00_系统/chushihua/日志后再写笔记，重试及重新实例化可读取未完成请求；其他设备不能接管请求，源文变化时停止。已有标识的笔记不重新编号。

“打开笔记校验侧栏”显示当前笔记字段错误与警告，切换笔记或修改文件会刷新。关闭新建窗口后已提交写入仍可完成，但不会主动打开新笔记；已保存笔记打开失败时重试仅重新打开。
