# DEV-014：十类业务记录中文字段迁移

2026-10-09；根据用户选择，采用实际中文字段，覆盖原拼音字段要求。契约1.4，业务文件格式版本3。

## 实施范围

九类Markdown笔记的YAML属性、隐藏系统信息及独立JSON记账行使用中文字段。实体值、三状态、收支和影视类型也使用中文。旧拼音格式版本2和新中文格式版本3都可读取；统一字段映射在存储边界恢复内部领域模型，因此索引、关联、校验、回收及操作恢复继续使用既有代码端口。实际写出的文件为中文，并非仅在界面替换标签。

所有新建及受保护更新输出中文字段，九个公开模板已迁移。中文日期/日期时间类型涵盖所有模块；校验侧栏显示中文字段。日记/待办/项目继续采用上一轮简洁属性规则：移出的字段保留在隐藏系统信息中，不回到属性栏。

用户自定义未知属性和嵌套内容原样保留，避免误改用户的数据。同一字段同时存在中文和拼音名称时拒绝合并，要求先处理原文件，不能静默选一个值。未知版本只读；版本3在内部兼容模型中转换成原领域版本2，不意味着允许使用旧插件写新版文件。

稳定标识、关联UUID、日期、金额分单位、原始正文与已完成操作日志保持原值。内部源码变量、配置及恢复日志的既有协议不强制更名，避免破坏原请求签名与恢复回执。这些不是原生业务笔记的属性名。

## 迁移与备份

scripts/migrate-chinese-fields.mjs提供两种明确范围：--templates转换九个公开模板；--vault转换本工程dev-vault中正式管理记录、已有用户模板和原生属性类型配置。完整预检后先备份，再逐文件比对原文写入并重读核对。未完成操作/初始化、别名冲突、非法格式或未知版本会停止。文件之间不承诺原子事务；中途失败保留备份和已经转换的文件，兼容读允许核对后重试。脚本不迁移隔离宿主验收样本、历史资料或个人远程Git仓库。

本次实际迁移：公开模板9份，测试库业务笔记4份，原生属性类型配置1份。当前测试库没有正式记账行，记账中文转换通过专项测试覆盖。
