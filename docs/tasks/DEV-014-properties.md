## 系统信息与兼容

结构版本jiegoubanben用于区分数据格式，版本不认识时只读，防止升级后误改旧笔记。它与创建时间、插件版本不同，也不是笔记修改次数；当前仍为2，保留在属性栏。无需日常编辑。

日记稳定标识仍用于关联、重复检查和恢复，改存于正文开头的隐藏HTML系统注释。三类移出属性栏的历史数据也保留在这条注释中，源模式可见；不是删除历史内容。shuxingmoshi=jianjie标记这种展示方式，bijishiqu保存创建时的配置时区。解码后恢复领域属性，自由正文不包含系统注释；更新保留未知属性与正文。损坏、冲突的系统注释拒绝写入。旧插件不保证识别此展示方式，降级前保留备份。

原生日期时间控件保存无偏移的本地分钟值时，按笔记保存的时区解析，不使用电脑时区；夏令时重复或不存在的时间拒绝解析，源模式需明确偏移。

Obsidian原生属性无单选类型。项目进度在LifeOS笔记校验侧栏提供三项中文下拉，选择后走现有安全操作服务，完成时补齐完成时间，回到进行中/未开始时清除完成时间。原生属性中仍为文本，也可以手工填写这三个中文值。不能将侧栏下拉宣称为原生属性单选。

## 使用与已有笔记

测试库安装日期类型后按Ctrl+R，新建笔记立即应用新文件名与属性。其他Vault可执行“配置笔记日期与时间属性类型”，再刷新；仅更新这些类型，保留其他配置，坏配置拒绝覆盖。

旧笔记不批量自动改名或改写。打开一篇旧日记/待办/项目，执行“整理当前日记待办项目的属性与文件名”，保留正文/标识/时间，整理属性，再通过公开FileManager改名更新笔记链接。同名目标阻止修改；写入与改名不是跨文件原子操作，失败后核对当前路径再重试。日记同日仍复用已有记录，不自动改动旧记录路径。安装模板仍不覆盖自定义模板，创建命令为这三类套用新展示规则。

同名待办/项目不会覆盖已有文件；需更换名称。九类其他模板仍沿用原有命名规则。
