# DEV-022：独立记账表单与行存储

2026-10-12；契约1.5，记账JSON结构不变。工程完成，真实桌面表单体验待确认，手机暂缓。

首页快速记录、记录页记账按钮及“LifeOS：新建记账”命令接入专用表单。填写日期、收入/支出、分类、金额（元）和标签；星期按有效日期即时预览，保存时由领域规则重新派生。默认今天使用配置时区。金额用文本输入，最多两位小数，转换为安全整数分保存，禁止零、负数、科学计数、非法或溢出金额。标签按逗号/中文逗号/换行分隔，去空白、去重复。

分类仅展示当前收支类型的启用项，切换收入/支出重新选择对应分类。服务校验收支、分类、标签及全记录规则，第一次执行前再次检查分类和模块启用状态；准备后分类停用则停止写入。已尝试保存的请求在重试时优先核对原操作回执，不重新生成记录或改金额。历史分类不因设置变化自动改写。分类边界的进一步规则验证由DEV-023完成。

LedgerService复用LedgerStore和持久操作日志，保存到记账模块shuju/UUID.json，实际文件使用中文日期、星期、收支、分类、标签、金额等字段，金额单位为分。不创建MD，不新增账户、转账、退款或余额。不同的明确新建请求是不同记录，不能因金额/日期相同误去重。

准备表单不写入；取消未提交表单不生成数据。快速重复提交用同步锁，同请求并发共用执行；输入在保存后锁定，未确认响应重试沿用原请求。窗口关闭后已提交写入可能完成，完成会通知且不重新打开窗口；卸载清理所有窗口与React根，停止后不继续后续操作或发迟到通知。索引刷新后可在回看搜索或日记当天汇总看到保存的行。完整数据表、编辑、统计及导出在DEV-024实现。
