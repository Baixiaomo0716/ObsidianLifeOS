# DEV-024：记账数据表与统计导出

2026-10-12；契约1.5，JSON结构不变。工程完成，真实桌面表格与下载行为待体验，手机暂缓。

LifeOS→回看→记账显示专用数据表，字段为日期、星期、收支、分类、标签、金额及操作。支持日期范围、收支、分类精确匹配、标签精确匹配、分类/标签文字搜索、回收记录切换和每页50行分页。表格限制高度并滚动，金额以元显示两位小数。筛选数据来自有效、无争议JSON行，回收视图和普通视图分开；无效、重复身份或旧转账退款不进入正常集合，提示索引问题。

统计和导出采用全部筛选结果，分页只影响显示。统计为收入、支出和结余，回收行不计金额；溢出显示错误，不返回部分统计或导出结果。无效日期范围显示错误并暂停导出。未初始化时不导出。

编辑预填原日期、收支、分类、标签和金额，星期由日期重新派生。历史停用/移除分类可在原收支类型下保留，新增分类分配必须使用启用项。只更新记账业务字段，保留原ID、文件路径、创建时间、未知属性及引用；更新时间由存储层维护。准备与首次执行均核对原文件版本，手工并发修改时暂停覆盖。未确认响应沿用同一操作日志请求恢复，不新建重复行。回收行需先恢复才能编辑。

每行可回收或恢复，复用TrashStore、版本核对与持久日志；保留原ID及所有关联，不删除文件。回收后移出正常统计，恢复后重新纳入。失败按钮沿用同一请求重试。窗口/页面退出后不重新打开编辑器；已提交写入可能继续完成，卸载后服务停止。

CSV为UTF-8 BOM、CRLF、全字段引号转义，日期/星期/收支/分类/标签/金额（元）/已回收；标签用顿号连接，公式起始文本加单引号，防止表格软件按公式执行。原始JSON导出为当前筛选行的原文件对象数组，保留中文或旧拼音原键、未知属性及整数分，不含操作日志，不保证源文件空白排版。导出覆盖全部分页，不修改Vault；页面通过浏览器下载入口生成文件。实际Obsidian桌面下载保存需验证，不宣称已经完成宿主下载验收。
