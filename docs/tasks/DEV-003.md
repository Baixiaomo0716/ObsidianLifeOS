# DEV-003：搭建插件工程

日期：2026-10-09；状态：已完成（工程静态验收）；所属P0/阻塞；前置DEV-001满足，DEV-002基础环境已由用户确认。
范围仅工程：不交付视图、命令、设置、业务表单或存储；这些归DEV-004及后续任务。

## 交付

package.json、pnpm-lock.yaml、pnpm-workspace.yaml、tsconfig.json、esbuild.config.mjs、manifest.json、versions.json、styles.css、src/main.ts、scripts/build-policy.mjs、scripts/verify-build.mjs。
插件标识life-os，工程版本0.1.0；manifest与数据结构版本2/文档PRD1.6独立。
默认生产产物位于dist/：main.js、manifest.json、styles.css；build-meta.json是本地验证报告，安装不需要。生成产物/依赖/缓存均忽略，不读取Vault、不推送个人数据。

## 依赖与兼容依据

本次Node24.19.0，pnpm11.25.0。固定React/react-dom19.3.0、TypeScript7.0.2、esbuild0.28.2、Obsidian API1.13.1、@types/node22.20.5、React类型19.3.0。
最低应用版本1.13.4取当前手机环境；API类型包没有1.13.4标签，使用已发布且低于手机版本的1.13.1，不升级到桌面1.14.4类型。入口当前仅依赖公开Plugin类，不使用较新API；每次新增API仍需检查最低版本，DEV-008在桌面1.14.4/手机1.13.4验证。isDesktopOnly=false是兼容目标，不是已通过真机测试。

参考[官方示例构建](https://github.com/obsidianmd/obsidian-sample-plugin/blob/master/esbuild.config.mjs)：CommonJS、ES2021、宿主obsidian外部依赖。LifeOS额外在解析阶段禁止Node内置模块和electron，含传递依赖；React只会在实际引用时打包，当前入口尚未使用UI库。
pnpm11构建权限配置在workspace文件，仅允许esbuild安装脚本，不允许全部依赖脚本。[pnpm设置](https://pnpm.io/settings)。
