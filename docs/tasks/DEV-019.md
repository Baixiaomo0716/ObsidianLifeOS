# DEV-019：日记多项关联与新建返回

2026-10-12；契约1.5，业务格式不变。九类笔记创建返回和日记分区工程完成；记账新建返回待DEV-022专用表单，真实桌面交互待体验，手机暂缓。

LifeOS→回看→日记的当天详情新增“当天自动汇总”和“显式关联”两个独立区域，均有高度限制和滚动。自动汇总只读，不自动写入日记关联；显式关联按稳定ID解析，缺失、回收或争议目标仍显示待核对，保留引用。打开笔记进入原生编辑器，记账打开只读详情。

自动汇总按配置时区判断创建和完成时间，并按业务日期展示开始阅读/读完、观看、演出、待办与项目开始/截止、旅行开始至结束的每日行程。影视上映、游戏发行等日期不作为个人活动。当天新增与活动重合时合并为一条并展示原因；已显式关联时加标记。关闭模块不参与自动汇总，原显式关联仍保留。无结束日期的旅行只匹配开始日。无效、重复身份、重复日记及回收记录按索引规则排除。

当日收入、支出和结余仅按有效账本行的日期属性计算，使用安全整数分；显式关联同一行不会重复计入，关联其他日期的账本也不改变当天金额。当天创建的旧日期账本可在自动区显示“当天新增”，仍不计入当天收支。金额累计溢出显示错误，不展示虚假零值。

有效日记点击“选择关联 / 新建并返回”，先选类型，再搜索、多选；类型切换保留原选择。九类MD均接入已有模板服务，可填写标题（日记填写日期）新建；保存后将实际文件身份附加到全部当前选择，返回选择区，可继续选或关闭返回日记。正文和其他笔记字段在原生编辑器继续填写。当天日记不能关联自身，其他日期已有有效日记复用。取消尚未提交的新建只退回选择，不创建实体。既有十类记录仍可关联；记账不展示可保存的新建伪表单。

创建前校验原日记及选项；执行后通过索引取得目标身份，再通过关联服务保存。新建与关联是两个有日志的步骤，不是跨文件事务：创建完成但关联失败时保留新笔记，提示错误；不删除新文件，也不覆盖同时被手工修改的日记。可重新打开选择器选已创建笔记后保存。未确认响应重试沿用原创建/关联请求，快速重复提交共用一次执行；取消/关闭后已开始保存可能完成，会报告结果，不重新打开窗口。插件停止后禁止后续步骤。
