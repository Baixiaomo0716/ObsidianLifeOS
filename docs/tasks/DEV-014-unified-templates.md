# DEV-014：九类模板属性统一

2026-10-10；契约1.5，业务文件格式仍为3；最新用户要求优先于上一轮展示规则。

## 已实现

九类Markdown模板统一使用原生tags属性，移除原生属性栏里的标签、标识、名称、已归档、已取消。标识、历史名称、归档和取消值保留在隐藏系统注释，维持已有引用和恢复能力。原标签合并到tags，已有原生tags与旧标签按顺序去重合并；格式冲突停止，不丢弃数据。

创建时间、更新时间均配置为原生日期时间；已有开始日期、截止日期为日期。其他业务日期时间仍按原口径配置。这些属性类型按名称在整个Vault共享。

日记不使用进度。其他八类笔记均使用“进度”列表，默认只有“未开始”一项，合法值为未开始/进行中/已完成。阅读原“状态”展示统一改为进度，内部仍兼容原阅读字段；知识新增进度，旧知识缺进度可读，迁移后默认未开始。空列表、多状态列表或未知值保留为无效初稿并提示，不静默挑选一项。

侧栏安全进度编辑覆盖八类，可补齐完成时间，阅读同时处理读完时间；原生属性类型仍为列表。直接手工改为已完成时仍需满足完成时间等原有规则，字段错误由侧栏报告。

所有新建笔记使用纯名称.md，日记保留YYYY-MM/YYYY-MM-DD.md。新建同名不覆盖，需要另一个名称。旧文件移除末尾UUID，同名时选名称（2）等可读编号，不丢失任一笔记。日常手工改名用Obsidian，内部隐藏历史名称保留兼容；后续浏览与搜索显示应以文件标题为准。
