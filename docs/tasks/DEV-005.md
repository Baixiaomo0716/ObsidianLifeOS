# DEV-005：公共模型与校验

日期：2026-10-09；状态：已完成（领域模块与工程验收）；前置DEV-001、DEV-003已满足。契约1.3、结构版本2。

## 交付

src/domain/entities.ts定义日记、记账、阅读、影视、游戏、演出、旅行、知识、待办和项目的独立类型，持久化字段及枚举用拼音。src/domain/validation.ts验证UUID v4、版本、字段类型、必填项、评分、字数、日期顺序、三状态及管理时间，提供显式输入规范化和日期派生函数。src/ports/clock.ts与id-generator.ts提供可替换的时间和标识接口；宿主实现归后续适配任务。

src/domain/money.ts使用十进制字符串和BigInt精确解析元到分，拒绝三位小数、非正数及安全整数溢出；分到元显示不经过浮点除法。汇总排除回收行，收入、支出累计分别检查安全边界，结余允许负数。

src/domain/progress.ts实现完成、重复完成、撤销完成和项目重新打开的纯规则。阅读历史读完时间可在显式保存准备时保留，并同步完成时间；离开完成清除两者。影视观看时间、演出活动时间不因完成而改写。取消/归档标记在普通进度切换时保留；项目重新打开清除。任务取消等完整服务操作仍归DEV-020/025。

日记neirong按Unicode码点计算，500允许、501拒绝；知识和自由正文不套用该限制。规范化仅处理当前实体已知字段，未知属性原样保留，长文本不裁剪。读取校验不修正源对象，原生笔记保存也不会被领域函数阻止。未知结构版本校验不通过，后续存储层必须只读处理。

## 历法与时区

纯日期校验真实年月日，时间要求ISO格式及明确偏移，范围至±14:00；今天使用指定时区，默认Asia/Shanghai，不依赖电脑默认时区。

农历实现选用宿主Intl.DateTimeFormat中国历法，显式指定Asia/Shanghai，以业务日期当地中午转换。产品开放公历1901-01-01至2100-12-31范围；越界、缺少中国历法或返回格式不能识别时报告不可用，不生成猜测值。年转中文数字，冬月/腊月规范为十一月/十二月，避免不同宿主名称差异造成不一致。修改日期时显式重算；读取旧星期/农历不一致只报错，不静默写回。

API依据：[ECMA-402 formatToParts](https://tc39.es/ecma402/#sec-intl.datetimeformat.prototype.formattoparts)。回归样例对照香港天文台[2023年公历与农历对照表](https://www.hko.gov.hk/en/gts/time/calendar/pdf/files/2023e.pdf)、[2024年对照表](https://www.hko.gov.hk/en/gts/time/calendar/pdf/files/2024e.pdf)：2024春节、端午、中秋，2023闰二月首日及2024除夕。当前Node运行时通过样例和范围端点测试，不代表整个范围逐日已验证，也不代表Obsidian手机Intl实现已验证；DEV-008必须在实际宿主复核相同样例及不支持提示。

## 关联边界

关联UUID去重并禁止自身；缺失目标保留并提示。提供RelationContext接收索引目标及旧关联：待办最多一个项目，新增归属到已完成、取消或归档项目拒绝，原有归属保留。索引键约定小写UUID；未传上下文时仅完成字段校验，并返回“目标关系尚未检查”提示。DEV-006/010/016必须接入实际索引才能保证跨记录约束；本模块不扫描Vault或检查全库UUID重复。

项目daiban为派生属性，未把手工列表当归属权威。上传文件只检查相对路径语法；真实Vault边界、文件存在、大小及导入成功需要存储/附件适配器确认。首页进行中判断使用各实体正确字段，并排除取消和归档；回收/冲突过滤归索引及查询层。
