# DEV-021：待办页面与项目关联

2026-10-12；契约1.5，业务格式不变。工程完成，真实桌面操作待体验，手机暂缓。

LifeOS→回看→记录类型“待办”显示专用工作台，提供收集箱、今天、逾期、全部、标题/正文/tags搜索和每页50条的分页。列表限制高度并滚动。有效待办才进入列表，回收、重复身份及无效字段由索引排除，索引问题数量提示用户检查。

按配置时区确定今天。未完成、未取消且未归档的待办按逾期优先归组：截止日早于今天为逾期；否则开始日或截止日为今天进入今天；无开始/截止日期且无可解析项目关联进入收集箱；其余仅在全部显示。全部包含完成、取消和归档记录并显示标记，不包含回收。四个标签页是筛选，全部包括其他组；单条记录在实际日期分组中仅属于一组。缺失引用继续保留并在关联选择器提示，无法解析成项目的引用不视为当前项目归属。读取和跨天重算不复制文件。页面每分钟及索引变化时刷新，离开释放计时器和订阅；设备休眠后刷新时重新取当前日期。

新建待办复用模板标题表单，名称即可创建并打开原生编辑器继续填写。列表的“编辑日期”提供开始日期和截止日期控件，可为空、可清除；开始日期不得晚于截止日期。保存只更新日期字段，保留正文、tags、关联和管理信息。准备与执行时核对原版本，原文件被同时修改则停止覆盖；未确认响应沿用原日志请求重试，不复制待办。取消未提交的日期编辑不写入；离开页面不重新打开迟到的编辑器，已提交写入可能完成。进度操作复用DEV-020窗口，打开标题进入原笔记。

“关联 / 项目归属”复用DEV-016选择器，可关联其他内容，最多一个项目；新增到已完成、取消或归档项目会拒绝保存。已有关闭项目引用可以保留或移出。移动归属只修改待办关联，不双写项目待办列表。项目列表和派生比例仍由DEV-025实现。关联选择器显示当前项目名称及不可用引用，解除关联保留目标文件。
