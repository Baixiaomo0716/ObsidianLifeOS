## 框架与溢出

以工作台容器宽度响应，避免桌面窄分栏仍套用大屏布局。宽于680px侧栏172px，内容卡片两列；不宽于680px切到底部四按钮、一列卡片。底栏保留安全区，触摸按钮最小48px；主区域min-width/min-height=0，页面纵向滚动，不横向扩张。

顶部页标题、底部状态提示和导航保持在页面滚动之外。首页卡片260px、记录页440px，卡片标题与操作栏不收缩，正文独立overflow-y:auto；回看/设置框使用剩余空间，短窗口设置框最低220px且页面仍可滚动。长路径/文本换行，网格minmax(0,1fr)避免长内容撑开。

手机样式在320px起设计，但实际手机、软键盘、100条长列表等验收仍归DEV-030；不能以容器CSS或模拟测试宣称真机通过。主题颜色使用Obsidian变量，样式主要限lifeos-root，不覆盖宿主全局按钮与布局。
