# LifeOS 验收与测试契约

版本：1.0；冻结日期：2026-10-08。依据：[PRD v1.3](../PRD-v1.0.md)、[架构](architecture.md)、[数据契约](data-schema.md)。

DEV-001 只检查契约完整性。下列产品测试**全部尚未执行**；表内任务表示实施与取证责任，不表示已通过。模拟测试不能替代真实设备、同步与恢复证据。

## 1. 验证层次与证据

- 单元：领域纯规则，固定时钟/时区/ID；覆盖合法值、边界和拒绝行为。
- 集成：真实文本编解码、端口实现和错误注入；检查原文/属性/附件实际落盘，不仅检查页面消息。
- 宿主：真实桌面与手机 Obsidian 加载产物、原生编辑器、文件选择、滚动和打开文件。
- 同步恢复：DEV-002 选定的一种实际同步服务，两设备离线和并发；独立备份恢复到空测试 Vault。

每份 `docs/qa/` 证据记录：日期、任务/验收编号、构建版本、设备/系统/宿主版本、同步服务版本或配置、数据规模、步骤、预期、实际、通过/失败/未执行、截图或文件差异、缺陷与复测。只使用合成数据，不上传私人笔记。失败写明结果，不把“计划覆盖”算作通过。

## 3. 固定数据与失败注入

1. 金额：CNY期初0，两账户；2026-09-30支出1250，2026-10-01退款500。9月净支出1250，10月净支出-500，累计750；再次退751拒绝、退750允许。另有收入2000和转账300，转账不改总收支。JPY exponent=0 单独显示，12.501 CNY拒绝；安全整数边界和溢出求和须拒绝。
2. 时间：固定2026-10-08T23:59:59+08:00到次日，今日任务重新分组但文件不复制；完成时间跨月按设置时区归属。包含闰日有效、非法2月30日、无偏移时间拒绝、设置时区改变不改历史date。
3. 项目：四任务2完成/1进行中/1取消；取消任务即便status=completed仍排除。归档有效任务仍计工作量；无任务显示暂无任务。完成每种处置在第2条写入失败后重试，已有步骤不重复，项目不提前完成。
4. 无损：正文含checkbox、双链、代码块、中文及换行；未知YAML含字符串、列表、布尔；表单只修改title。保存前后比较未知属性语义和正文原文。冲突在读后写前注入，原版本不得丢失。
5. 幂等：写成功但返回错误、关系步骤失败、上传复制完成后列表写失败，重启再用原operation_id恢复；实体/文件数不增加。不同请求同操作ID报错。
6. 完整性：同ID两文件、同日日记、未知schema、断关系、无效金额、回收与冲突副本。异常记录不进入正常统计，不删除原文；修复/恢复后重建一致。
7. 关联：十类各一个实体，作品各子类型；切换类型保留选择，重复点选仅一个ID，自关联拒绝；新建后附加日记失败再恢复，不重复目标、不丢选择。
8. 附件：两同名不同内容、空文件、20MiB及超限1字节、未知MIME、非法相对路径、部分复制失败、共享两项目；未同步不可用与本地成功分开，移出一处另一处可用。
9. 布局：320px、常用手机和桌面窄分栏；100项进行中、100关联、50附件、超长标题；滚到末尾操作，键盘焦点可见，表单键盘弹起仍可保存。尺寸记录来自实际容器。
