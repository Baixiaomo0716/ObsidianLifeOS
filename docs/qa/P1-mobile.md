## 桌面执行步骤

1. Ctrl+R重新加载插件，打开LifeOS首页；分别在宽分栏、约680px及320px窄分栏、短窗口中检查。实际宽度由命令报告，不要求目测准确。
2. 命令面板运行“LifeOS：检查当前工作台布局”，复制报告。命令仅测当前已渲染页面，不切页、不写业务数据；提示不可见时先显示工作台。多个LifeOS窗口时检查取首个已注册视图，报告不可见需先关闭多余工作台或显示对应视图。
3. 首页/记录/回看/设置分别检查，记录宽高、主题、是否有横向撑开、导航及标题可达、卡片末尾是否能滚到。账本表格允许在框内横向滚动，页面本身不应横向溢出。
4. 使用独立测试库的长标题、长正文、100条记录或已有足量样本，检查待办、项目、附件、关联候选及已选列表。分页时到最后一页；滚动后选择仍保留，关联类型切换保留多选。不要在真实库批量制造测试记录。
5. 关联选择器、新建记账、日期编辑、项目关闭及附件上传弹窗检查：末尾按钮可达，窄窗口按钮换行，Tab/Enter可操作，关闭后不重新弹出。固定卡片内部滚动和页级滚动均需手动核对。布局命令不检查弹窗和焦点顺序。
6. 深浅主题各复测一次；手机恢复验收时补触摸、软键盘升起后的输入/保存、返回键、旋转及实际文件选择/打开。
