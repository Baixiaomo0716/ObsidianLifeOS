2026-10-19：新增 680px 及以下工作台适配，按插件面板实际宽度响应，覆盖手机竖屏及桌面窄分栏。

- 四项底部导航保留至少 48px 高度，并留出底部安全区。
- 首页、记录、回看、设置使用页面连续滚动，卡片按内容展开。
- 快速记录改为单列，项目看板、标签面板改为单列；筛选和操作按钮可换行。

- 弹窗限制在动态视口内，表单在窄屏改为单列；宿主管理软键盘引起的可用高度变化。

## 安装

将构建产物 main.js、manifest.json、styles.css 一起复制到手机 Vault 的 `.obsidian/plugins/life-os/`，重新启用插件。使用 BRAT 的用户需等待相应 GitHub 版本发布；本地改动不会自动到达手机。

## 验证状态

完整 `pnpm check` 通过，包含移动端依赖禁用检查。自动化检查不能替代 Android/iOS Obsidian 真机验收。内置浏览器拒绝访问本地预览文件，本次没有完成视觉验证。尚未验证软键盘、刘海/底部安全区、系统文件选择和导出下载行为。

## 真机检查步骤

1. 在 320、390、430px 左右的竖屏及横屏下打开四个页面，确认导航可见、页面无框架横向溢出，所有末尾内容和保存操作可达。
2. 首页新建日记、记账、待办，填写长标题；弹出软键盘后滚到保存按钮，保存并重开核对内容。
3. 回看中切换所有记录类型、标签、月年度回顾，确认筛选可操作，账本可左右滑到编辑列，项目看板可查看全部状态。
4. 在关联选择弹窗中搜索、跨类型选择、取消及保存；打开系统文件选择器导入附件，核对附件可重开。
5. 分别测试 CSV/JSON 导出，确认系统实际保存文件。移动端系统对浏览器下载支持不同，未实际取得文件不能视为导出成功。
6. 测试深浅主题、旋转、后台恢复及外接键盘焦点。运行 LifeOS 布局诊断，配合人工检查；诊断通过不代表全部页面已经验收。
