## 3. 固定样本与故障

使用固定时钟和标识：2026-10-08（星期四）及跨日边界；历法测试选可查证节日、闰月和范围边界，不凭猜测样例。
金额12.50→1250；12.501、0、负金额及安全整数溢出拒绝；收入2000支出1250结余750。
日记内容用500/501码点，包括中文、表情、空格换行；YAML多行、冒号、引号、代码块和未知值类型往返不丢失。
项目2完成+1进行中+1取消比例2/3；注入第二条写入失败，项目保持未完成，重试不重复成功步骤。
记账写入成功响应失败、目标新建后关系失败、附件复制后项目更新失败，沿同操作标识恢复不重复。
附件同名不同内容、20MiB边界、未知类型、路径穿越、共享两项目及尚未同步；逐项结果真实。
320px、窄分栏、100关联、100进行中、50附件、超长名称和手机键盘，末项与保存按钮可达。
