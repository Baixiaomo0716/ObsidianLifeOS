# LifeOS 开发预览安装与使用

2026-10-12，0.1.0开发预览。建议先在专用测试Vault体验；万条数据保存性能尚未达标，真实多端和恢复验收仍保留。交付ZIP只包含插件与说明，不包含笔记、账本、令牌或本地设置。

## 安装

1. 解压交付ZIP，确认life-os文件夹内有main.js、manifest.json和styles.css三份文件。CHECKSUMS.json记录交付文件摘要；先核对来源及预览说明。
2. 在Obsidian中打开目标Vault，关闭LifeOS后，把life-os文件夹放到该Vault的.obsidian/plugins/下。不要把整个源码目录、ZIP或文档目录放进插件目录。Windows资源管理器需显示隐藏文件才能看到.obsidian。
3. Obsidian设置→第三方插件，按自己的使用偏好允许第三方插件并启用LifeOS。最低声明1.13.4，建议使用已确认的桌面1.14.4；版本声明不是所有版本或手机的验收证明。
4. Ctrl+R重载，Ctrl+P执行“LifeOS：打开LifeOS”（搜索LifeOS即可找到），也可用侧边图标。源码测试库已安装，可直接重载查看。

本插件没有内置Git自动拉取/推送功能。源码仓库与个人笔记仓库分开，使用已配置的同步软件；界面不宣称“已同步”。记账是每笔独立JSON行，不能当作单个Excel文件或MD笔记编辑。

## 日常使用

首页可快速创建日记、记账、待办；进行中事项只显示进行中且未取消/归档的记录。记录页提供九类MD模板和记账表单。MD笔记可在原生编辑器填写属性与正文；进度是列表，只选未开始/进行中/已完成之一，多选会被视为无效记录。日期及日期时间沿用Obsidian属性类型，不能随意改成非日期文本。

回看页按类型进入日记、待办、项目、账本、阅读、影视、游戏、演出、旅行和知识工作台。日记选择关联先选类型，再多选；新建返回保留选择，关联失败保留新记录，请核对后重试或选择已有记录。项目待办由待办引用反查；完成项目用管理流程逐项选择处理方式，不直接批量改原笔记。

附件上传会实际复制并核验后关联；移出项目只解除引用，文件仍保留。支持的格式如何打开由Obsidian决定。记账列表可筛选、编辑、回收恢复和导出CSV/原JSON；导出下载仍需宿主体验。操作失败时先保留提示，优先重试同一请求，不盲目再建记录。Git冲突需核对双方内容，未解决的完整冲突块不参与正常查询，插件不会自动合并。

## 升级与回退

先停止编辑/同步，完成Vault外备份，保留当前插件三文件及版本/摘要，再关闭LifeOS。只替换插件目录内main.js、manifest.json、styles.css，保留data.json及Vault内业务/系统文件。启用并Ctrl+R重载，核对目录、时区、分类、记录数量、索引问题及附件。

已有同版本0.1.0多次预览构建，必须使用交付目录时间和摘要区分，不能仅靠版本号确认代码更新。没有自动迁移或无条件跨版本回退承诺。遇到新结构不兼容先关闭插件，保留当前数据，在新空Vault中恢复备份与对应旧插件验证；不要用旧数据覆盖正在使用的Vault或让旧插件改写未知字段。

## 卸载

先关闭LifeOS，保存未提交的原生编辑并确认正在进行的操作结果。Obsidian中禁用或卸载LifeOS；不要同时删除LifeOS业务根、附件、系统日志或回收与冲突目录。笔记仍是Markdown，账本仍是JSON，插件卸载不应作为清理数据操作。笔记中的隐藏元数据用于保留身份，需继续保留；账本可用原JSON或CSV导出另行读取。

## 备份与恢复

暂停编辑/同步，备份完整Vault（含业务根、附件、系统日志、回收/冲突、模板及.obsidian中的配置/插件），复制到Vault之外，记录路径、大小和摘要。Git历史不替代独立备份，同盘快照不防物理盘故障，异盘目标仍需配置。

恢复到新空目录，核对文件摘要，再用对应插件重读/重建索引，检查笔记、账本金额、关联和附件。不要覆盖当前Vault试恢复。迁移先备份和预览，再明确执行；保留无法映射及争议文件。参考docs/backup-and-migration.md。

## 已知限制与验收

万条合成混合样本下，查询约0.32秒、首页汇总约0.40秒、保存约18.6秒；后者未达目标，操作日志/全索引重建流程可能更慢。真实Obsidian性能和万条账本滚动尚未测。桌面布局用命令“检查当前工作台布局”辅助，但弹窗、软键盘、焦点和真实手机需人工验收。

恢复与同步现有证据仅覆盖合成文件快照、本地Git两个工作区；不等同个人Gitee、手机、独立物理备份或真实宿主恢复通过。正式验收状态见docs/qa/P1-acceptance.md。交付包是开发预览，无需把真实笔记上传至源码仓库。

阅读工作台支持作者/来源/正文搜索、进度与tags筛选、分页和资料编辑。新建仍填写Markdown模板，名称在原笔记中重命名；完成可填历史读完时间，重新开始会清除读完时间。时间输入按当前设备时区。

影视工作台支持导演/主演/内容搜索和类型、进度、tags筛选。编辑时导演主演每行一人，上映时间填写日期，观看时间按当前设备时区填写日期与时间，豆瓣评分手动填0–10。重新开始保留观看时间并清除完成标记。新建继续调用Markdown模板。

游戏工作台：回看选择游戏，按名称/内容、类型、进度和tags查询；类型自由填写，发行时间为日期，评价与正文可编辑。名称在原笔记中重命名，新建沿用Markdown模板。

演出工作台：回看选择演出，可搜索乐队、地点与内容并筛选类型、进度和tags。乐队/地点每行一项，演出时间按当前设备时区填写日期与时间，评分0–10；重新开始会保留演出时间并清除完成标记。新建调用Markdown模板。

旅行工作台：回看选择旅行，可搜索地点、交通、住宿与内容，筛选进度和tags。起止日期使用日期格式，允许同日旅行或仅填一端，结束不能早于开始；地点/交通/住宿每行一项。重新开始保留行程日期，名称在原笔记中重命名。

项目看板：回看选择项目，点击看板。三栏分别显示未开始、进行中、已完成，每栏独立滚动和翻页；默认不含取消/归档，可勾选查看。点击卡片打开项目详情，再使用编辑或关闭/重开流程。搜索会重新分页，切回列表保留详情。

知识工作台：回看选择知识，搜索内容或正文并筛选tags、进度；点击笔记名查看内容、正文和关联到它的日记/待办。编辑内容与正文分别保存，正文可填写[[笔记名]]双链和![[附件]]，在原笔记中打开链接。日记关联中可新建知识并返回，失败重试不会重复创建。

标签浏览：回看点击标签浏览，选择记录类型与标签。左侧标签显示该范围全部有效记录的数量，右侧可搜索标签下的记录并打开原笔记；两列表分别翻页。标签名按完整名称匹配，大小写和可选#前缀统一匹配，不修改原笔记。正文双链在原笔记中打开。切回记录浏览会保留记录类型。

月年度回顾：回看→月年度回顾，选择月份或年份。完成按配置时区下的完成时间，重新开始后不计完成，归档仍计；同一知识的新增与完成在全部列表合并。选择核对类型并点击原记录，列表每页50条。金额超出安全范围会提示，不显示虚假零。
