# 首页三列与灵感便签

首页以「首页三列灵感便签效果图.png」为布局参考：轻量六项累计统计；左列今天、日记入口、待办及截止提醒；中列快速记录与进行中事项；右列最近记录与灵感便签。桌面按容器可用高度分配各区块，更多记录在卡片内滚动，窄屏转为纵向排列。

累计、本周小结、支出、项目关联待办进度和旅行倒计时均来自有效索引记录。最近记录展示前三条，「查看全部」进入回看。阅读记录目前没有百分比字段，仅展示真实的阅读状态，不使用效果图中的示例百分比。

## 灵感便签

- 启用知识模块后可用；点击「记下灵感」打开输入窗口，支持1至2000字。
- 保存为知识目录中的 Markdown 笔记，包含「灵感便签」标签，正文与内容字段同步保存。
- 首页显示最近更新的一条便签；点击可编辑。「查看全部」显示便签列表，并支持编辑和打开原笔记。
- 保存失败保留同一个操作请求以便重试；编辑前检查原版本，外部修改后不会覆盖新内容。
- 回收记录不在便签列表中显示，保留原有恢复机制。
