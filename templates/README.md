# 十类笔记模板

将十份模板复制到Vault的LifeOS/00_系统/模板/，在Obsidian核心Templates设置中选择该文件夹；在新笔记中调用对应模板。不要把本README当实体模板。

当前是模板源，不是插件产物；biaoshi及系统时间需由后续LifeOS创建命令生成。核心Templates仅替换title/date等标准变量，不生成UUID。空属性是可填写占位，软件校验后可省略未填可选字段，未知属性不删除。模板目录必须排除业务索引。

进度值：weikaishi/jinxingzhong/yiwancheng。记账jine单位分，例如1250=12.50元。日记neirong最多500码点。项目daiban派生只读、shangchuanwenjian需命令真实复制文件。

详细方案见[模板笔记录入说明](../docs/template-entry.md)。
