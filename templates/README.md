# 九类笔记模板

2026-10-10；契约1.5，业务文件格式3。日记、阅读、影视、游戏、演出、旅行、知识、待办、项目共九个模板；记账仍用独立JSON和专用表单。

所有模板使用原生tags，属性栏没有标签、标识、名称、已归档、已取消。文件标题承担名称，稳定标识与历史名称等存入隐藏系统注释，请保留注释。原标签值迁移到tags，中文字段与旧拼音字段兼容读取。

创建时间/更新时间使用原生日期时间，开始日期/截止日期使用日期。日记没有进度，其他八类统一为进度列表，默认未开始；每条只填未开始、进行中、已完成中的一项。阅读旧状态兼容转换，知识也有进度。

LifeOS新建命令自动生成标识、时间和必要派生字段；核心Templates手工调用后可执行初始化当前模板笔记标识和时间命令。无效初稿保留，校验侧栏报告问题。使用侧栏选择完成会补齐完成时间，阅读同时处理读完时间。

日记文件名为YYYY-MM/YYYY-MM-DD.md，其他八类新建为纯标题.md，不附UUID。同名新建不覆盖，需要另一个标题；旧文件清理遇同名保留可读编号。

安装九类模板命令创建缺失模板、更新可识别的默认模板，保留自定义模板。当前测试库模板与笔记已备份迁移，刷新Obsidian后重新打开文件查看。属性类型在Vault按属性名共享。

详见[当前数据契约](../docs/data-schema.md)、[统一模板记录](../docs/tasks/DEV-014-unified-templates.md)。历史模板与执行记录只供对照。
九类模板均已补齐正文：日记记录生活，待办使用带截止时间的 TODO 清单；阅读、影视、游戏、演出、旅行各自记录体验与感受，知识整理问题与原理，项目组织目标、里程碑与复盘。完整正文集中记录在[笔记模板正文格式](../docs/笔记模板正文格式.md)。新建笔记时会自动更新已安装的默认模板并带入最新正文，无需手动同步；自定义模板及已有笔记保留原文。默认版本保存在 00_系统/模板版本，供后续更新识别使用。
