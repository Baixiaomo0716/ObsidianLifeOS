# LifeOS

基于Obsidian的人生管理系统：九类Markdown模板笔记与独立JSON记账数据表。当前为0.1.0开发预览，已有418项自动化检查通过；首期全量验收未通过，手机按用户要求暂缓。

## 可以使用的功能

- 首页今日支出、今日待办、八类进行中事项及最近记录。
- 日记按月份保存纯日期笔记；九类笔记使用中文属性、原生tags及隐藏身份，原生编辑器填写正文。
- 专用收支表单、账本筛选编辑、回收恢复、统计及CSV/原JSON导出。
- 十类关联多选及新建返回；待办日期/状态/项目归属，项目反查比例、逐项关闭和持久恢复。
- 项目附件真实复制、核验、打开、移出引用和失败重试。
- 无损写入、版本冲突保护、独立副本、操作回执、完整性检查和索引重建；未解决的完整Git冲突块不进入正常查询。

阅读、影视、游戏、演出、旅行和知识已有模板录入、搜索及关联，后续独立业务页与P2/P3验收继续保留。

## 安装与体验

交付包解压后，把life-os文件夹放到目标Vault的.obsidian/plugins/下，启用第三方插件中的LifeOS，Ctrl+R重载后打开LifeOS。只安装main.js、manifest.json、styles.css；首次建议在专用测试Vault体验。详细步骤见[安装与使用](docs/install-and-use.md)。

开发测试库位于本工程dev-vault，已忽略且不上传个人数据。Obsidian“打开文件夹作为仓库”选择该目录；源码仍在本工程。每次构建自动复制不会替换已经加载的代码，需要Ctrl+R重载。最低宿主声明1.13.4，Windows Obsidian1.14.4基础加载和重开有用户确认；isDesktopOnly=false是兼容目标，不代表手机已验收。

## 构建与交付

使用Node22及以上、pnpm11.25.0；本机验证Node24.19.0。ZIP打包需要PowerShell7的pwsh命令。

```sh
pnpm install --frozen-lockfile
pnpm check
pnpm install:vault
pnpm dev:vault
pnpm package:preview
```

check执行类型、生产构建、产物/移动依赖、领域/存储/操作/关联/业务/恢复等检查。dev:vault持续监听，成功构建后复制到测试库；提交或打包前停止监听。package:preview先执行完整检查，再制作releases/内独立预览ZIP并解压核对路径/数量/摘要；版本保持0.1.0，构建时间与摘要区分同版本预览。build-meta.json不用于安装。

交付包只含插件三文件、安装说明、更新记录、验收与性能/备份资料、CHECKSUMS.json，不含源码、真实Vault、令牌或本地配置。dist、releases、node_modules、本地测试与备份目录不提交。操作记录和技术配置保持各自协议，业务文件中文格式3、内部结构2。

阅读专页：回看选择阅读，可按作者/内容、进度和tags筛选，编辑资料、阅读时间、评价与正文；新建调用原生笔记模板。详见docs/tasks/DEV-034.md。

影视专页：回看选择影视，支持导演/主演/内容搜索、类型/进度/tags筛选，编辑影视资料、观看时间和正文。豆瓣评分手动填写，所有内容仍记录在Markdown笔记。详见docs/tasks/DEV-035.md。

游戏专页：回看选择游戏，支持名称/内容搜索、类型/进度/tags筛选，以及资料、发行日期、评价和正文编辑；新建沿用Markdown模板。详见docs/tasks/DEV-036.md。

演出专页：回看选择演出，支持乐队/地点/内容搜索、类型/进度/tags筛选，并编辑演出时间、地点、评价、评分与正文；新建沿用Markdown模板。详见docs/tasks/DEV-037.md。

旅行专页：回看选择旅行，支持地点/交通/住宿/内容搜索、进度/tags筛选，以及起止日期、多地点、交通住宿、评价与正文编辑；新建沿用Markdown模板。详见docs/tasks/DEV-038.md。

项目看板：回看→项目→看板，按三状态分栏、每栏独立滚动和分页，卡片打开现有项目详情。P2工程验收证据及未验证项见docs/qa/P2-acceptance.md。

知识专页：回看选择知识，支持内容/正文搜索、进度/tags筛选、内容正文编辑和被关联记录回看；原生双链语法原样保存，在原笔记中打开。详见docs/tasks/DEV-040.md。

标签浏览：回看切换标签浏览，可按记录类型查看tags及记录数量，选择标签后搜索并打开原记录。标签列表与内容分别分页，统计排除停用/回收/争议记录。详见docs/tasks/DEV-041.md。

月年度回顾：回看→月年度回顾，按月份或年份核对收入、支出、结余、日记及八类完成记录、新增知识，并打开原记录。口径和验收见docs/tasks/DEV-042.md与docs/qa/P3-acceptance.md。
